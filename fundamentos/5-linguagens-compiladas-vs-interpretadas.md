# Diferença entre Linguagem Compilada x Interpretada

## Conceitos Fundamentais

### 1. Linguagens Compiladas
- **Características**
  - Código fonte transformado diretamente em código de máquina
  - Execução mais rápida
  - Verificação de erros em tempo de compilação
  - Resultado é um arquivo executável
- **Exemplos**
  - C/C++
  - Rust
  - Go
  - Swift

### 2. Linguagens Interpretadas
- **Características**
  - Código executado linha por linha
  - Maior flexibilidade
  - Verificação de erros em tempo de execução
  - Necessita de um interpretador
- **Exemplos**
  - Python
  - JavaScript
  - Ruby
  - PHP

### 3. Comparação

#### Vantagens e Desvantagens

**Compiladas:**
- ✅ Execução mais rápida
- ✅ Menor uso de memória
- ✅ Detecção de erros antecipada
- ❌ Processo de desenvolvimento mais lento
- ❌ Código menos portável

**Interpretadas:**
- ✅ Desenvolvimento mais rápido
- ✅ Maior portabilidade
- ✅ Mais flexível
- ❌ Execução mais lenta
- ❌ Maior uso de memória

### 4. Casos Híbridos
- Java (JVM)
- C# (.NET)
- Kotlin
- Scala
