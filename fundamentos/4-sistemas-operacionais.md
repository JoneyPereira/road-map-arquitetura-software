# O que são Sistemas Operacionais?

## Conceitos Fundamentais

### 1. Funções Principais
- **Gerenciamento de Processos**
  - Escalonamento
  - Estados dos processos
  - Comunicação entre processos
- **Gerenciamento de Memória**
  - Alocação
  - Paginação
  - Memória virtual
- **Sistema de Arquivos**
  - Organização
  - Permissões
  - Hierarquia
- **Gerenciamento de Dispositivos**
  - Drivers
  - Interrupções
  - E/S

### 2. Tipos de Sistemas Operacionais
1. **Desktop**
   - Windows
   - macOS
   - Linux
2. **Mobile**
   - Android
   - iOS
3. **Servidor**
   - Linux Server
   - Windows Server
4. **Embarcado**
   - RTOS
   - QNX

### 3. Kernel
- Monolítico
- Microkernel
- Híbrido
- Exokernel

## Componentes Essenciais
1. Shell
2. Interface Gráfica
3. Sistema de Arquivos
4. Gerenciador de Processos
