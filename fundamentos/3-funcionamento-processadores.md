# Como os processadores funcionam?

## Conceitos Fundamentais

### 1. Arquitetura Básica
- **Unidade de Controle (UC)**
  - Coordena operações
  - Decodifica instruções
  - Controla fluxo de dados
- **Unidade Lógica e Aritmética (ULA/ALU)**
  - Realiza operações matemáticas
  - Executa operações lógicas
  - Processa dados
- **Registradores**
  - Memória ultra-rápida
  - Armazena dados temporários
  - Diferentes tipos e funções

### 2. Ciclo de Instrução
1. Fetch (Busca)
2. Decode (Decodificação)
3. Execute (Execução)
4. Store (Armazenamento)

### 3. Pipeline
- Paralelismo de instruções
- Otimização de execução
- Hazards e soluções

### 4. Cache
- L1, L2, L3
- Hierarquia de memória
- Política de cache

## Arquiteturas Modernas
- RISC vs CISC
- Multicore
- Hyperthreading
- ARM vs x86
