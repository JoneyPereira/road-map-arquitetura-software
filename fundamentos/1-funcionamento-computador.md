# Como funciona um computador?

## Conceitos Fundamentais

### 1. Hardware Básico
- **Processador (CPU)**: O cérebro do computador
  - Executa instruções
  - Realiza cálculos
  - Controla outros componentes
- **Memória RAM**: Armazenamento temporário
  - Armazena dados em uso
  - Acesso rápido
  - Volátil (perde dados ao desligar)
- **Armazenamento**: HD/SSD
  - Armazenamento permanente
  - Mais lento que a RAM
  - Mantém dados mesmo desligado
- **Placa-mãe**: Conecta todos os componentes
  - Barramentos de dados
  - Slots de expansão
  - Portas de entrada/saída

### 2. Fluxo de Dados
1. Input (entrada de dados)
2. Processamento
3. Output (saída de dados)
4. Armazenamento

### 3. Sistema Binário
- Como os computadores trabalham com 0s e 1s
- Conversão entre decimal e binário
- Representação de dados em bits e bytes
